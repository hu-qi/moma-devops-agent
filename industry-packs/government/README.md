# Government Industry Engineering Pack (政务行业工程包)

## 概述

本工程包是 DevOpsPilot 面向信创政务系统研发的行业知识与工程规约底座。它独立于核心 Agent 运行时，通过标准化声明注入领域知识。

## 规范范围

1. **等保 2.0 合规（GB/T 22239-2019）**：
   - 关键操作审计留痕；
   - 敏感信息（公民身份证、手机号、信用代码）强制脱敏。
2. **信创平台兼容**：
   - ARM64 / LoongArch 跨架构适配支持；
   - 隔离外网依赖，严禁公网动态依赖拉取。
3. **安全审查门禁**：
   - 杜绝硬编码密码与密钥；
   - 自动化审计完整性测试门禁。

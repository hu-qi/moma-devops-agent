# Finance Industry Engineering Pack (金融行业工程包)

## 概述

本工程包是 DevOpsPilot 面向金融核心交易、银行账务与证券支付业务的专用工程规约包。它提供交易幂等性约束、金额浮点数禁用、卡号合规脱敏及金融审计门禁。

## 规范范围

1. **敏感金融数据保护（PCI-DSS 4.0 / JR/T 0071）**：
   - 银行卡号（PAN）前6后4掩码；
   - 严禁明文记录敏感鉴权数据（CVV2、交易密码）。
2. **交易与动账幂等（JR/T 0197）**：
   - 所有状态写入接口强制附带并校验唯一 `idempotency_key`。
3. **金额精度与防浮点误差**：
   - 统一使用 `Decimal` 或整型分计算金额，杜绝二进制浮点舍入误差。
4. **测试门禁**：
   - 自动化浮点金额运算防御门禁。
